One line, 113 characters: the funniest out-of-office auto-reply a person could actually set, judged head to head by an AI judge.

Entry for the [make.fun competition "The Funniest Out-of-Office"](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf).

## What it does

`main.ts` (Node 22) writes a single out-of-office auto-reply to `/output/entry.txt`. The reply:

> I'm away until Monday. Your email was forwarded to future me, who is equally behind and considerably more tanned.

## Run it

```sh
node main.ts
```

That writes `/output/entry.txt`. For a local run, point the output elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-ooo node main.ts
```
